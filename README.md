# IIUM-PalmaCount
Satellite-Based Tree Counting and Area Estimation in Palm Oil Plantations Using Deep Learning.

# Project Overview
PalmaCount is an automated system developed to address the challenges of manual tree counting in large-scale palm oil plantations. By leveraging high-resolution satellite imagery and state-of-the-art Deep Learning models, this project provides:

- Automated Detection: Identifying individual palm trees even in crowded or overlapping crown conditions.
- Precise Counting: Providing an accurate inventory for yield prediction and resource management.
- Area Estimation: Calculating the total land coverage and plantation density.
- Visualized AI results with bounding boxes

This project is part of the research initiatives at the International Islamic University Malaysia (IIUM), focusing on AI-driven precision agriculture.
